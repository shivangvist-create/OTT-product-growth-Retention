# OTT Product Growth & User Retention Analysis

## Product Management Case Study

For this project, I looked at a simple product problem in an OTT app. 
A lot of users may sign up and watch content once, but not all of them continue using the app regularly.

The main aim of this case study is to understand user behaviour and think about what can be done to improve retention.

## Problem

Getting new users is important, but keeping them active is also important for an OTT platform.

I looked at the user journey from opening the app to watching content and coming back to the app again.

## User Segmentation

I considered some basic user groups:

- New users
- Returning users
- Trial users
- Paid users
- Highly active users

Looking at these groups separately can help understand how different users behave.

## User Journey

The basic user journey considered in this case study is:

**App Open → Search/Browse → Watch Content → Trial/Subscription → Return to App**

I wanted to understand where users may stop using the app.

## Retention Metrics

Some of the metrics I considered are:

- Day 1 Retention
- Day 7 Retention
- Day 30 Retention
- Average Watch Time
- Repeat Usage
- Subscription Conversion

These metrics can help understand whether users are continuing to use the product.

## Product Idea

One idea I considered is improving **personalized content recommendations**.

For example, if a user usually watches a particular type of content, the app can show more relevant content on the home screen.

The main idea is to make it easier for users to find something they want to watch.

## A/B Testing

I also considered how this idea could be tested using an A/B test.

**Control Group:** Existing recommendation system

**Treatment Group:** Personalized recommendation system

The two groups can then be compared using metrics such as:

- User Retention
- Average Watch Time
- Content Engagement
- Subscription Conversion

## What I Learned

Through this case study, I worked with:

- User segmentation
- Retention metrics
- User journey
- Product metrics
- A/B testing
- Product improvement ideas

The main thing I learned is that before adding a new feature, it is useful to understand the actual user problem and decide how the impact will be measured.

## Note

This is a personal product management case study based on simulated assumptions. The data is not from a real OTT company.
